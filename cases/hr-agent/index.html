项目背景

他们是怎么陷进去的

某企业每到招聘季，HR 部门每天要处理 200-300 份简历，其中真正符合岗位要求的不超过 15%。HR 花大量时间在「看不合适的简历」和「发重复的初筛消息」上，而真正有价值的工作——和候选人深度沟通、判断文化匹配、做 offer 谈判——却因为时间不够做不好。我们为其搭建了 HR 全流程智能体，让机器处理筛选和触达，人来处理判断和决策。

涉及模块

简历解析 Agent岗位匹配评分主动触达外呼面试自动调度候选人数据库

核心挑战

招聘效率低、HR 被重复工作淹没、优质候选人响应慢

我们的解法

简历解析 + 岗位匹配评分 + 自动触达 + 面试调度 Agent

最终成果

初筛效率提升 10 倍，优质候选人响应时间从 2 天缩短到 2 小时

Pain Points

这些痛，你是否似曾相识？

这些不是假设的问题，是我们进场前真实存在、已经拖了很久的困境。

01

每天 200+ 份简历，HR 根本看不完

招聘季的简历量远超 HR 处理能力，大量简历积压未看，部分优质候选人因为响应太慢而已经接受了其他 offer。HR 处于疲于应付的状态，根本没有精力做深度评估。

02

初筛标准不统一，靠人工判断误差大

不同 HR 对同一份简历的评价差异很大，同一个岗位今天看简历的标准和明天不一样，导致筛出来的候选人质量参差不齐，后续面试通过率低。

03

沟通全靠手动，一条一条发消息

给候选人发初筛通知、面试邀约、安排时间——每一步都要 HR 手动操作。候选人多的时候一天光发消息就要花 2 小时，而且经常出现发漏、发错的情况。

Our Solution

我们做了什么，怎么做的

每一项解决方案直接对应一个痛点，不是通用方案的套用。

01

简历解析 + 多维评分，初筛变成客观判断

Agent 自动解析简历结构化信息（教育、经验、技能、项目），对照岗位 JD 进行多维匹配评分，输出「推荐 / 待定 / 不合适」分层结果，并标注关键匹配点和差距。HR 看评分结果而不是原始简历。

02

主动触达 Agent：推荐候选人秒级响应

评分合格的候选人由 Agent 自动发送初筛通知，包含岗位介绍、薪资范围、下一步流程，邀请确认意向。候选人回复后 Agent 自动更新状态，需要人工介入时才推送给 HR。

03

面试调度 Agent：对齐双方时间，自动发出邀约

候选人确认意向后，Agent 自动拉取面试官可用时间段，发送时间选择链接，候选人选择后自动生成日历邀约、发送确认邮件和提醒。面试安排从人工对话缩短到全自动完成。
